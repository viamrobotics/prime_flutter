A basic text input field.

## With Icons

Inputs can have leading and trailing icons.

<Preview src="input?style=withIcons" height="150px">

```dart
Input(
  placeholder: 'Search...',
  leading: Icon(PrimeIcons.magnify),
  trailing: Icon(PrimeIcons.close),
)
```

</Preview>

## Password

Inputs can be used for passwords with `obscureText`.

<Preview src="input?style=password" height="150px">

```dart
Input(
  placeholder: 'Password',
  obscureText: true,
  leading: Icon(PrimeIcons.lock),
  trailing: Icon(PrimeIcons.viamFlutter),
)
```

</Preview>

## Validation

Validate in your own code and show the result through the field: `state: InputState.error` turns the input red and adds an error icon, and a `Hint` inside a `Field` takes the error color. Check on submit, as below, or on every change with `onChanged`.

<Preview src="input?style=validation" height="220px">

```dart
String? error;

Column(
  children: [
    Field(
      required: true,
      state: error != null ? InputState.error : InputState.none,
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.stretch,
        spacing: 4,
        children: [
          const Label(label: Text('Machine name')),
          Input(controller: name, placeholder: 'my-rover'),
          Hint(child: Text(error ?? 'Letters, numbers and dashes.')),
        ],
      ),
    ),
    Button(
      variant: ButtonVariant.primary,
      label: const Text('Save'),
      onPressed: () => setState(() => error = name.text.trim().isEmpty ? 'Enter a machine name.' : null),
    ),
  ],
)
```

</Preview>
