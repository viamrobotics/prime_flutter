`IconButton` is an icon-only action. Give it a `label`: it becomes the accessible name and the tooltip.

## Variants

`primary`, `secondary`, `ghost`, `ghostOutline`, `danger`, `dangerFilled`, and `dark`. `size` is `medium` (36px) or `large` (44px), and `loading` swaps the icon for a spinner.

<Preview src="demo?name=icon-button" height="200px">

```dart
IconButton(
  icon: const Icon(PrimeIcons.trashCanOutline),
  label: 'Delete',
  variant: IconButtonVariant.danger,
  onPressed: delete,
)
```

</Preview>
