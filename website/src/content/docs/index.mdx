Welcome to the Prime Flutter documentation. This site demonstrates the components available in the `prime_flutter` library.

## How it Works

This documentation site is built with [Astro Starlight](https://starlight.astro.build) and embeds the live Flutter application using iframes.

### Running the Docs Locally

To run this documentation site you need Flutter 3.50 or later. The repo pins its version with [FVM](https://fvm.app) in `.fvmrc`, and the build uses FVM when it is installed.

```bash
cd website
npm run dev
```

### Running the Flutter Embed

The interactive demos rely on a running instance of the Flutter web application.
The `npm run dev` command handles building the Flutter app automatically.

If you make changes to the Flutter code in `website/playground/lib` or `lib/`, you simply need to let the prebuild script run again (restart the dev server or run `npm run build:flutter`).

## Playground

The examples shown in this documentation are powered by a dedicated "Playground" Flutter app located in `website/playground`.
